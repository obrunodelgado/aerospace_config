# Configuração do Aerospace

O arquivo `.aerospace.toml` deste repositório possui customização das configurações do AeroSpace. Foi adicionado a configuração necessária para integrar o Junky Borders com o AeroSpace, as cores das bordas utilizam uma paleta cyberpunk e há um respiro de 10 unidades de distância entre cada janela.

## Pré-Requisitos
Ter o AeroSpace e o Junky Borders instalado. As instruções de instalação podem ser encontradas nos seguintes repositórios:
- https://github.com/nikitabobko/AeroSpace
- https://github.com/FelixKratz/JankyBorders

## Instruções
Faça uma cópia das configurações do AeroSpace localizadas em `~/.config/.aerospace.toml`. Em seguida, copie o conteúdo do arquivo `.aerospace.toml` localizado neste repositório para dentro do arquivo `~/.config/.aerospace.toml`.

Reinicie o AeroSpace para aplicar as alterações.
